## 1. What this app is (one paragraph)

ShelfScan is a mobile-first web app (installable PWA) for one person. I scan the barcode of a book I bought, the app looks it up and saves it into my virtual library on my phone. In the library I can sort and filter my books. When I don't know what to read, I tap a mood button (e.g. "romance", "happy", "cozy") and the app suggests unread books from my library that fit. The whole app is cute, pastel and pink, and each book gets its own soft color theme based on its cover.

## 2. Non-negotiable rules

1. **Everything must be free.** No paid services, no API keys, no backend, no accounts. This is a static frontend only.
2. **No Claude/LLM calls inside the app.** Mood matching works through a genre/keyword table (see section 7).
3. **Data stays on the device** in IndexedDB. The only network calls are book lookups (Open Library, Google Books) and fonts are bundled locally (no Google Fonts CDN).
4. **TypeScript strict mode**, no `any`.
5. **Mobile first.** Design for a 390px wide phone screen first, then make it work on desktop.
6. Keep code simple and readable. Prefer small files and small functions. Add a short comment only where the intent is not obvious.

## 6. Data model

Define in `src/data/db.ts`:

```ts
type ReadStatus = 'unread' | 'reading' | 'read';

interface Book {
  id: string;                 // crypto.randomUUID()
  isbn13: string;             // unique index
  title: string;
  authors: string[];
  pageCount?: number;
  description?: string;
  subjects: string[];         // raw subjects from the API
  genres: string[];           // cleaned genres (see genres.ts)
  coverBlob?: Blob;           // cover image stored locally
  themeHue: number;           // 0-360, used for this book's pastel theme
  status: ReadStatus;         // default 'unread'
  rating?: 1 | 2 | 3 | 4 | 5;
  tags: string[];             // user tags
  notes?: string;
  dateAdded: number;          // Date.now()
  source: 'openlibrary' | 'googlebooks' | 'manual';
}
```

Dexie table `books` with indexes: `id`, `&isbn13`, `title`, `dateAdded`, `status`.

### Scoring (`src/lib/recommend.ts`)

Write one pure function:

```ts
recommend(books: Book[], selectedMoodIds: string[], options?: { maxPages?: number; excludeIds?: string[] }): ScoredBook[]
```

Rules:
1. Candidates are only books with `status === 'unread'`, minus `excludeIds`, minus books over `maxPages` (if set).
2. Build a search text per book: lowercase of `title + subjects + genres + tags + description`.
3. For each selected mood, count how many of its keywords appear in the text. Genre/subject matches count **2 points**, description-only matches count **1 point**.
4. Mood score = sum across selected moods. If a book scores 0 for all selected moods, drop it.
5. Tiebreaker: older `dateAdded` first (books waiting longest get priority). Small random jitter (±0.5) so "Show another" feels fresh but results stay deterministic when a seed is passed (accept an optional `seed` for tests).
6. Return the top 5 with a `reason` string like `"Matches: romance, rivals"` listing the matched keywords.

If nothing matches, the UI shows a friendly message: "Nothing in your unread pile matches this mood yet 🌸 Try another mood or add more books!" plus a "Surprise me" button that picks a random unread book.

## 8. Barcode scanning flow

`Scanner.tsx` + `ScanPage.tsx`:

1. Ask for camera permission with `facingMode: 'environment'`. If denied, show a friendly message and the manual ISBN field.
2. Continuous scanning, only accept codes that are valid ISBN-13 (start with 978 or 979, correct checksum). Ignore everything else silently.
3. On a valid scan: vibrate (`navigator.vibrate?.(80)`), flash the viewfinder border pink, then run `lookup`.
4. Ignore the same ISBN for 3 seconds (debounce).
5. If ISBN already exists in the library: show a toast "Already in your library 💗" with a button to open that book. Do not duplicate.
6. If lookup succeeds: save book, show a cute confirmation card (cover, title, author) with an **Undo** button visible for 5 seconds.
7. If lookup fails: open `ManualAddForm` pre-filled with the ISBN (title, author, pages required fields: title only).
8. **Batch mode toggle**: camera stays open and added books stack in a list under the viewfinder.
9. Always provide a text field "Type ISBN" and a "Search by title" option as backup.

### Lookup (`src/lib/lookup.ts`)

Order: Open Library → Google Books → return `null`.

- Open Library: `https://openlibrary.org/api/books?bibkeys=ISBN:{isbn}&format=json&jscmd=data`
- Google Books: `https://www.googleapis.com/books/v1/volumes?q=isbn:{isbn}`
- Cover URL: `https://covers.openlibrary.org/b/isbn/{isbn}-L.jpg?default=false` (the `default=false` makes it return 404 when no cover exists instead of a blank image)
- Normalize both into the same `LookupResult` shape. Add a 8-second timeout per request. Never throw to the UI; return `null` on failure.
- Tests must use saved fixtures in `tests/fixtures/`, never real network.

### Per-book theme (this is the special feature)

Every book has a `themeHue` (0-360). Wherever a single book is shown (BookCard background, BookDetail sheet, Pick results) set CSS variables inline from that hue so the card is tinted to fit the cover:

```css
--book-bg:     hsl(var(--hue) 85% 94%);   /* very light tint */
--book-accent: hsl(var(--hue) 75% 78%);   /* chip/button color */
--book-strong: hsl(var(--hue) 60% 62%);   /* text accents, hearts */
```

How to compute `themeHue` in `src/lib/cover.ts`:
1. Download the cover as a Blob (store it as `coverBlob`).
2. Draw it into a 32×32 canvas, read pixels, ignore near-white/near-black/gray pixels (low saturation), and take the average hue of the remaining pixels weighted by saturation.
3. If there is no cover or the canvas read fails (CORS), fall back to a stable hash of the title mapped into a pretty pastel-friendly range: hues between 320–360 and 0–40 (pinks/roses/peaches) and 250–290 (lavender).
4. Always apply the fixed pastel saturation/lightness above, so even a dark red or black cover becomes a soft pastel. Result: a book with a cold blue ice-hockey cover gets a soft icy-blue-pink tint, a fiery red one becomes warm rose, etc.
